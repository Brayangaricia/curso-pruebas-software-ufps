# Curso de Pruebas de Software – UFPS

## Descripción

Este repositorio contiene la implementación académica y técnica del curso “Pruebas de Software” desarrollado para el Programa de Ingeniería de Sistemas de la Universidad Francisco de Paula Santander (UFPS) en la plataforma Moodle.

El curso fue diseñado bajo un enfoque teórico-práctico orientado a la industria del software, integrando fundamentos de calidad, pruebas funcionales, pruebas de APIs, automatización, pruebas de rendimiento e integración continua (CI/CD).

---

# Objetivo General

Desarrollar un curso virtual de Pruebas de Software en Moodle que permita fortalecer las competencias necesarias para asegurar la calidad de aplicaciones y preparar a los estudiantes para las necesidades actuales de la industria del software.

---

# Arquitectura del Curso

El curso fue diseñado bajo una estructura modular progresiva compuesta por cinco módulos académicos.

Cada módulo integra:
- contenido programático,
- recursos multimedia,
- infografías,
- contenido audiovisual,
- actividades prácticas,
- evaluaciones,
- y material complementario.

La organización modular permite mantener trazabilidad pedagógica, reutilización de recursos y escalabilidad dentro de la plataforma Moodle.
